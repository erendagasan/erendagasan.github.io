mnist classifier on custom risc-v.

-

i made a mnist classifier which runs on custom risc-v core. the core itself is running on basys3 fpga.

it all started with my desire to run a risc-v core on fpga then play doom on it but it turned out that this is not the easiest task to start learning systemverilog and hardware design. so i ended up designing a core to run a simple mlp model on it.

classifying 7 as 7 :)

//achieving single cycle execution

a single cycle risc-v processor executes an entire instruction from the rv32i instruction set in one clock cycle. in my case the instruction set was not rv32i but rv32im. the difference is you have the multiplication and division instructions on top of integer operations. i'll explain the details later why we needed the "m" operations.

in every clock cycle our processor does below operations:

  1. instruction fetch
  2. decode
  3. execute
  4. memory access
  5. writeback
